Este primer bloque estudia el rendimiento logarítmico acumulado a una y dos sesiones. Los pronósticos se originan al cierre; su precisión no equivale a la rentabilidad de una estrategia que ejecuta al cierre de la sesión siguiente.

Regresiones simples a 5 minutos

Se estima una regresión por acción: el rendimiento logarítmico de la acción es la variable dependiente y el rendimiento de VOO del mismo intervalo es la explicativa. Se usa la misma muestra para los diez modelos, incluyendo las observaciones fuera del horario regular cuando los once activos tienen cierres válidos en ambos extremos.

leer_5m <- function(activo) {
  archivo <- if (activo == "AAPL") "APPL_5m.xlsx" else paste0(activo, "_5m.xlsx")
  encabezado <- saltos_5m[[activo]] + 1L

  x <- readxl::read_excel(
    archivo,
    range = readxl::cell_limits(c(encabezado, 2L), c(NA, 5L)),
    col_types = c("date", "skip", "skip", "numeric")
  )

  segundos <- round(as.numeric(x[["Exchange Time"]]))
  cierre <- x[["Close"]]
  ok <- is.finite(segundos) & segundos %% 300 == 0 &
    is.finite(cierre) & cierre > 0

  if (!any(ok)) stop("No se leyeron cierres válidos en ", archivo)

  d <- data.frame(
    Hora = as.POSIXct(segundos[ok], origin = "1970-01-01", tz = "UTC"),
    Close = cierre[ok]
  )
  if (anyDuplicated(d$Hora)) stop("Horas duplicadas en ", archivo)
  names(d)[2] <- activo
  d
}

Modelos y selección de predictores

La caminata aleatoria sin deriva pronostica un cambio de cero. El AR(1) en rendimientos equivale a un ARIMA(1,1,0) con deriva en logprecios. La regresión usa el rendimiento de la acción y el de VOO conocidos al cierre del origen; la variable dependiente es el rendimiento acumulado posterior. Se usa una regresión distinta para cada horizonte.

ajustar <- function(ticker, t, h) {
  r <- R[, ticker]
  m <- R[, "VOO"]
  # El último objetivo usado para estimar termina en t.
  i <- seq_len(t - h)
  acumulado <- c(0, cumsum(r))
  datos <- data.frame(y = acumulado[i + h + 1L] - acumulado[i + 1L],
                      propio = r[i], mercado = m[i])
  lm(y ~ propio + mercado, data = datos)
}

pronosticar <- function(ticker, t, h) {
  r <- R[, ticker]
  m <- R[, "VOO"]
  ar <- tryCatch(
    stats::arima(r[seq_len(t)], order = c(1, 0, 0), method = "ML"),
    error = function(e) NULL
  )
  c(Caminata = 0,
    ARIMA = if (!is.null(ar) && isTRUE(ar$code == 0))
      sum(predict(ar, n.ahead = h)$pred) else NA_real_,
    Regresion = as.numeric(predict(ajustar(ticker, t, h),
                                   newdata = data.frame(propio = r[t], mercado = m[t]))))
}

Evaluación cronológica y pronóstico

Por activo y horizonte, los primeros 40 orígenes eligen el modelo por RMSE y los últimos 40 evalúan esa elección frente a la referencia. Se deja un origen de separación para que el último objetivo de selección ya se conozca al iniciar la evaluación. Cada ajuste usa solo información disponible en su origen. Las pruebas t de la regresión son descriptivas: a dos sesiones los objetivos se solapan y los errores estándar convencionales pueden ser inadecuados.

n <- nrow(R)
evaluar <- function(ticker, h) {
  modelos <- c("Caminata", "ARIMA", "Regresion")
  seleccion <- seq.int(n - h - 80L, n - h - 41L)
  prueba <- seq.int(n - h - 39L, n - h)
  origenes <- c(seleccion, prueba)
  pred <- t(vapply(origenes, function(t) pronosticar(ticker, t, h),
                   setNames(numeric(3), modelos)))
  colnames(pred) <- modelos
  observado <- vapply(origenes, function(t)
    sum(R[seq.int(t + 1L, t + h), ticker]), numeric(1))
  e <- observado - pred
  rmse <- function(x) if (all(is.finite(x))) sqrt(mean(x^2)) else Inf
  ganador <- modelos[which.min(apply(e[seq_along(seleccion), , drop = FALSE], 2, rmse))]
  idx <- length(seleccion) + seq_along(prueba)
  error <- e[idx, ganador]
  futuro <- pronosticar(ticker, n, h)[[ganador]]
  banda <- if (all(is.finite(error)))
    futuro + quantile(error, c(.05, .95), names = FALSE) else c(NA_real_, NA_real_)
  co <- coef(summary(ajustar(ticker, max(seleccion), h)))
  list(tabla = data.frame(Activo = ticker, Horizonte = h, Modelo = ganador,
                          RMSE_prueba = rmse(error),
                          RMSE_caminata = rmse(e[idx, "Caminata"]),
                          MAE_prueba = mean(abs(error)),
                          Pronostico_pct = futuro,
                          P05_empirico_pct = banda[1],
                          P95_empirico_pct = banda[2],
                          P_propio_conv = co["propio", "Pr(>|t|)"],
                          P_VOO_conv = co["mercado", "Pr(>|t|)"]),
       error = error, fechas = fechas_r[prueba])
}

Escenarios del portafolio

Ejemplo con pesos iguales al inicio del horizonte. Se remuestrean vectores completos de errores fuera de muestra para conservar movimientos conjuntos, y se suman al pronóstico en escala logarítmica. Los percentiles son escenarios empíricos aproximados, no probabilidades garantizadas; solo se disponen de 40 orígenes de prueba por horizonte.

Backtest diario

Cada acción recibe inicialmente un décimo del capital, en efectivo. Cuando su cierre ajustado supera su media móvil de 50 sesiones, se invierte la fracción asignada a esa acción; de lo contrario, se mantiene en efectivo. La señal se conoce al cierre y se ejecuta al cierre de la sesión siguiente. La ventana de 50 sesiones se fija sin optimizarla sobre la muestra. Esta regla se evalúa por separado de los pronósticos de una y dos sesiones.

El capital inicial es de USD 1,000,000, sin ventas en corto ni apalancamiento. Se permiten unidades fraccionarias y se usan cierres ajustados como aproximación, sin modelar deslizamiento ni intereses sobre efectivo. Se descuentan USD 10 por compra o venta como supuesto basado en la comisión promedio observada. Al final se valoran las posiciones abiertas sin forzar su liquidación.

  p <- P_bt[, activo]
  media <- stats::filter(p, rep(1 / ventana_bt, ventana_bt), sides = 1)
  (p > as.numeric(media))[filas_bt - 1L]  # señal del cierre anterior

simular_bt <- function(precio, senal, capital, costo) {
  efectivo <- capital
  unidades <- 0
  operaciones <- 0L
  valor <- numeric(length(precio))
  for (i in seq_along(precio)) {
    if (senal[i] && unidades == 0 && efectivo > costo) {
      unidades <- (efectivo - costo) / precio[i]
      efectivo <- 0
      operaciones <- operaciones + 1L
    } else if (!senal[i] && unidades > 0) {
      efectivo <- unidades * precio[i] - costo
      unidades <- 0
      operaciones <- operaciones + 1L
    }
    valor[i] <- efectivo + unidades * precio[i]
  }
  list(valor = valor, operaciones = operaciones)
}

cartera_bt <- function(senales, costo) {
  posiciones <- lapply(acciones, function(activo)
    simular_bt(P_bt[filas_bt, activo], senales[, activo],
               capital_bt / length(acciones), costo))
  list(valor = rowSums(sapply(posiciones, function(x) x$valor)),
       operaciones = sum(sapply(posiciones, function(x) x$operaciones)))
}

for (i in seq_len(nrow(plan_htmw))) {
  posicion <- plan_htmw$Posicion_previa[i]
  estado <- plan_htmw$Estado_objetivo[i]
  precio_ref <- plan_htmw$Cierre_ajustado[i]

  if (estado == "Efectivo" && posicion > 0L) {
    plan_htmw$Cantidad_propuesta[i] <- -posicion
  } else if (estado == "Invertido" && posicion == 0L) {
    presupuesto <- min(tope_compra, efectivo_restante)
    cantidad <- floor(max(0, presupuesto - comision_supuesta) / precio_ref)
    plan_htmw$Cantidad_propuesta[i] <- cantidad
    if (cantidad > 0L) {
      efectivo_restante <- efectivo_restante -
        cantidad * precio_ref - comision_supuesta
    }
  }
}
